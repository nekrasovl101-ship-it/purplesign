PurpleSign

Подписывай и ставь IPA прямо с iPhone — своим Apple ID, без компьютера.

iOS 17+ Без джейлбрейка Свой Apple ID

Как установить

Выбери способ. Новичкам — Способ 1.

1 Своим Apple ID Всем подходит · бесплатно

Скачай IPA и подпиши его своим Apple ID — работает на любом iPhone и не слетает по чужому серту.

Скачать IPA
  1. Открой скачанный файл в AltStore, Sideloadly или ESign.
  2. Войди своим Apple ID (он подпишет приложение твоим бесплатным сертификатом).
  3. Нажми установить. PurpleSign появится на домашнем экране.
  4. Настройки → Основные → VPN и управление устройством → профиль → Доверять.
2 Быстрая установка (OTA) Нужен платный аккаунт

Установка в один тап прямо отсюда. Работает, только если твой UDID добавлен в сертификат (платный Apple Developer, Ad Hoc). На бесплатном аккаунте — используй Способ 1.

Установить по OTA

Открывать в Safari. Если выдаёт «Повторите попытку позже» — твоего UDID нет в серте, иди Способом 1.

3 С компьютера (Mac) по кабелю Как AltServer · бесплатно

Подключаешь iPhone кабелем к Mac, запускаешь установщик, вводишь свой Apple ID — и PurpleSign ставится. Модель AltServer на движке xtool.

Скачать для Mac (.dmg)
  1. Открой PurpleSign-Installer.dmg и перетащи приложение в «Программы».
  2. Запусти: правой кнопкой по иконке → «Открыть» → «Открыть» (один раз, оно не из App Store).
  3. Подключи iPhone кабелем, включи VPN, нажми «Доверять компьютеру».
  4. В окне: 1. Войти в Apple ID → 2. Установить. IPA уже внутри.
  5. Серт бесплатный — раз в 7 дней запускай установку заново.

Нужен xtool (brew install xtool-org/tap/xtool). Windows: ставь через Sideloadly — тоже кабель + свой Apple ID.

Что умеет

  1. Подпись на лету — сертификат, Apple ID или готовый IPA.
  2. Магазин источников — репозитории AltStore / SideStore.
  3. Три способа ставить — iOS, LocalDevVPN или сохранить файл.
  4. Контроль сертов — видно срок и отзыв, не слетит молча.

Важно: PurpleSign работает по модели SideStore — каждый ставит его своим Apple ID. Это честный путь без чужих энтерпрайз-сертов, которые Apple отзывает.
